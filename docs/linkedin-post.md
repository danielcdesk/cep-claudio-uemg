# Rascunho para o LinkedIn

Desenvolvemos uma landing page para consultar logradouros e CEPs de Cláudio (MG) como atividade prática do curso de Sistemas de Informação da UEMG Carangola.

A página reúne as respostas das consultas de Rua, Avenida e Praça à API ViaCEP em um arquivo JSON local. A busca sugere endereços a partir de três caracteres e apresenta bairro, localidade e CEP. A interface foi feita com HTML5 semântico, CSS3 e JavaScript puro, sem frameworks.
