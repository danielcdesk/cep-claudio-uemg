    Sobre o projeto

    Esta página é uma atividade prática do curso de Bacharelado em Sistemas de Informação da Universidade do Estado de Minas Gerais, Unidade Acadêmica de Carangola. O projeto exercita HTML semântico, CSS, JavaScript e o consumo local de dados abertos.

    INFORMAÇÃO AO VISITANTE

    Termos de uso

    Finalidade acadêmica

    Esta aplicação possui finalidade didática e informativa, vinculada às atividades do curso de Sistemas de Informação da UEMG Carangola.

    Origem e atualização dos dados

    Os registros foram obtidos pelas consultas à API pública ViaCEP para Rua, Avenida e Praça em Cláudio (MG), em 18 de novembro de 2026. A página apresenta uma cópia local dos resultados e não consulta o cadastro dos Correios em tempo real.

    Uso das informações

    Os dados são exibidos para consulta. A equipe não garante que correspondam à situação cadastral mais recente e não se responsabiliza por divergências, indisponibilidade ou uso comercial indevido. Confirme informações importantes diretamente nos canais oficiais dos Correios.

    INFORMAÇÃO AO VISITANTE

    Privacidade

    Busca no navegador

    O texto digitado é comparado localmente, no navegador, aos registros do arquivo JSON. O projeto não inclui ferramentas próprias de análise, rastreamento, pixels ou cookies de publicidade.

    Dados pessoais

    A página não solicita nem armazena dados pessoais. O provedor de hospedagem pode processar registros técnicos de acesso conforme suas próprias políticas.

    Área de transferência

    O CEP só é enviado à área de transferência quando a pessoa aciona o botão “Copiar”.
